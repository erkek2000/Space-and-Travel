# Space and Travel

A 3D spaceflight prototype focused on piloting a spaceship and travelling among planets.

## Features

- Controllable 3D spaceship
- Multiple planet models
- Third-person camera system
- Switchable physics modes
- Spaceflight visual effects

## Getting started

1. Install Godot 4.6 or a compatible Godot 4 release.
2. Import `project.godot` in the Godot Project Manager.
3. Open the project and press **F6** or **F5** to run it.

## Project structure

- `assets/` — planet and spaceship models, textures, and VFX
- `scenes/` — game scenes and reusable objects
- `scripts/` — spaceship, camera, physics, and game-management logic
